# SaruTask v0.1.1

指定フォルダ内のタスク用フォルダとMarkdownを検索するWindows常駐アプリです。

- 「ヘルプ(H)」メニューに「更新」と「バージョン」を追加しました。
- GitHub Releasesから最新正式版を確認し、ZIP版を使って更新・再起動できます。
- インストーラ版とZIP版を用意しました。
- 初期状態では指定フォルダの直下のみ検索し、サブフォルダ検索へ切り替えられます。
- Ctrl + Alt + Tで呼び出し、Escまたは×でトレイに隠せます。

Windows 10 / 11用です。初めて使う場合は`SaruTask-0.1.1-Setup.exe`、インストールせずに使う場合は`SaruTask-0.1.1-win.zip`を選んでください。
